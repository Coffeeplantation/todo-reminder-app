# 📋 Todoリマインダー

タスクボードと予定管理を統合した、シンプルで強力なタスク管理アプリです。ブラウザで動作し、オフラインでも使用可能。Excel との相互運用にも対応しています。

## 🌟 主な機能

### 📊 タスクボード
- **複数ボード管理**: 月別・プロジェクト別など、複数のタスクボードを同時管理
- **ドラッグ&ドロップ**: タスクをボード間で簡単に移動
- **期日管理**: タスク期日を指定して、自動でボード分類
- **ボード最小化**: タスク数が多い場合、ボードをタイルサイズに縮小可能
- **ボード結合**: 複数ボードを組み合わせて表示

### 🗓️ 予定管理
- **現行予定表**: ボード内のすべてのタスクと、インポートした予定を一元表示
- **期日ソート**: 自動的に期日順にソート
- **ボード連携**: タスクが属するボード名を表示

### 📥 予定インポート
- **複数フォーマット対応**: Excel（.xlsx/.xls）、CSV、カレンダー（.ics）、テキスト、URL
- **AI解析**: 自由形式のテキストから自動的に予定を抽出（ローカルAI対応）
- **一括取り込み**: インポートした予定をまとめてボードに追加

### 🤖 AI機能（完全ローカル）
- **ローカルAIのみ**: PC内の Ollama で動作（クラウドAIは使用しない・データを外部送信しない）
- **予定抽出**: テキスト・画像・メールから自動的に予定・タスクを抽出
- **メールボックス読み込み**: 「メールボックス読み取り.vbs」でOutlookフォルダを書き出し、現行予定表へ取り込み

### 🕐 常駐エージェント（24時間自動収集・完全ローカル）
- **自動収集**: PC内に常駐し、メールボックス・予定表リンク・メール本文中のリンクを定期的に読んで、予定をタスクボードへ自動追加（忘れ防止）
- **出典の明記**: 自動追加された予定には「どのメール／リンクから読み取ったか」が記録され、カード詳細・現行予定表で確認できる
- **リマインダー自動化**: 期日が近づいたらリマインダーメールをOutlookで自動送信、または下書きを自動作成（設定で選択）
- **起動方法**: 「エージェントを開始.vbs」をダブルクリック、または「エージェント常駐登録.ps1」でログオン時自動起動を登録
- **プライバシー**: 127.0.0.1 のみで動作。メール・タスク内容がクラウドへ送信されることはない

### 💾 データ管理
- **ローカルストレージ**: ブラウザのストレージにデータを保存
- **Excel 連携**: 仕様書（Excel）から自動的にタスクを読み込み
- **JSON形式**: エクスポート・インポート対応

### ⚙️ カスタマイズ
- **リマインド設定**: 期日の何日前にリマインドするか設定可能
- **署名設定**: メール送信時の署名をカスタマイズ
- **外観カスタマイズ**: ボードの背景色・影・サイズを個別設定

## 🚀 使用方法

### ブラウザで開く
```bash
cd browser
python -m http.server 8000
```
ブラウザで `http://localhost:8000` を開く

### Excel（VBA版）で使用
`Todoリマインダー.xlsm` を開く

## 📋 システム要件
- **ブラウザ版**: モダンなウェブブラウザ（Chrome、Firefox、Safari等）
- **Excel版**: Microsoft Excel 2016 以上
- **AI機能**: Ollama（オプション・完全ローカル）

## 🔧 セットアップ

### 1. リポジトリをクローン
```bash
git clone https://github.com/Coffeeplantation/todo-reminder-app.git
cd todo-reminder-app
```

### 2. ブラウザ版を実行
```bash
cd browser
python -m http.server 8000
# http://localhost:8000 でアクセス
```

### 3. ローカルAI（Ollama）をセットアップ（オプション）
- [Ollama](https://ollama.ai) をインストール
- `ollama pull qwen2.5:3b` で軽量モデルをダウンロード
- アプリ設定で Ollama のエンドポイントを指定

## 📝 使用例

1. **新しいボードを作成**: 「新しいボードを作成」ボタンをクリック
2. **タスクを追加**: ボード内の「＋」ボタンからタスクを追加
3. **予定をインポート**: 「自動タスク作成」から Excel/CSV/テキストを取り込み
4. **期日を設定**: タスクの期日を指定すると自動的に月別ボードに分類
5. **タスク状態を更新**: タスクをドラッグして状態を更新
